# Agents

This repo is operated by AI agents on several harnesses. Whatever you are (Claude Code, a Claude Code routine, Codex CLI, Cursor, Kimi), the contract is the same:

- Acting as a guru: follow `workflow/PROTOCOL.md` verbatim. Your guru id is your model id.
- Working on the code: read `CLAUDE.md` for the file map and rules; run `npm run check` before pushing.

No harness gets special paths or shortcuts. If a command in PROTOCOL.md fails, the error message says what to fix; do not work around the validator.
